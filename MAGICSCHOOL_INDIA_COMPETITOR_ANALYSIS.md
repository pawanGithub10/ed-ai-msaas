## 🛠️ Tech Stack

### Frontend:
- **Web App:** Next.js 14 + TypeScript + TailwindCSS
- **Mobile App:** React Native (iOS + Android)
- **UI Components:** Shadcn/ui, Radix UI
- **State Management:** Zustand / React Query

### Backend:
- **API:** Node.js (Express) + Python (FastAPI for ML)
- **Database:** PostgreSQL (user data) + MongoDB (content)
- **Cache:** Redis (for API rate limiting)
- **Queue:** BullMQ (for async AI generations)

### AI/ML:
- **LLM:** GPT-4 Turbo (via Azure OpenAI for India data residency)
- **Fine-tuning:** Custom models on Indian curriculum data
- **Translation:** Google Cloud Translation API
- **Moderation:** OpenAI Moderation + custom filters
- **On-device ML (for student app):** TensorFlow Lite

### Infrastructure:
- **Hosting:** AWS Mumbai (ap-south-1) or Azure India
- **CDN:** Cloudflare (for speed)
- **Auth:** Supabase Auth or Auth0
- **Storage:** S3 for media files
- **Monitoring:** Sentry, LogRocket

### Integrations:
- **Google Classroom API**
- **Microsoft Graph API (Teams, OneDrive)**
- **DIKSHA API** (if available, or web scraping)
- **WhatsApp Business API**
- **Payment Gateway:** Razorpay (Indian UPI/cards)

### Security & Compliance:
- **Data Encryption:** At rest (AES-256) and in transit (TLS 1.3)
- **DPDP Act Compliance:** Parental consent workflows
- **Data Residency:** All data stored in India
- **Privacy:** No training AI on student data
- **Penetration Testing:** Quarterly audits

## 🚧 Challenges & Risks

### 1. **MagicSchool Enters India**
**Risk:** They could localize and crush us with brand power

**Mitigation:**
- Move fast, build network effects (teachers share content)
- Lock in government partnerships early
- Focus on student hub (they don't have this)
- Deeper localization (they can't compete on 10+ languages quickly)

### 2. **Low Willingness to Pay**
**Risk:** Indian teachers/schools might not pay

**Mitigation:**
- Strong free tier (build habit)
- Demonstrate ROI (time saved = money saved)
- CSR funding for govt schools
- Government procurement (they have budget)

### 3. **Data Privacy Concerns**
**Risk:** Parents/schools worried about student data

**Mitigation:**
- Be privacy-first (no data training)
- DPDP Act certification
- Transparent privacy policy
- Parental consent workflows

### 4. **AI Output Quality (Hallucinations)**
**Risk:** AI generates wrong lesson content

**Mitigation:**
- Fine-tune on verified curriculum data
- Add verification layer (teacher must review)
- Feedback loop (teachers rate outputs)
- Disclaimer: "AI-generated, please verify"

### 5. **Infrastructure (Internet, Devices)**
**Risk:** Target schools can't access cloud platform

**Mitigation:**
- Offline mode from Day 1
- Mobile-first design (teachers use phones)
- SMS/WhatsApp integration
- Pre-loaded content on pen drives (for very remote schools)
